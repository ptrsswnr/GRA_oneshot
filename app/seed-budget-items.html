🌱 ใส่ตัวอย่างงบประมาณโครงการ (budgetItems)

หน้านี้ใช้ครั้งเดียวตอนตั้งค่า/ทดสอบระบบ — ใส่รายการประมาณการค่าใช้จ่ายตัวอย่าง 2 รายการ ลงใน users/{uid}/projects/{projectId}/budgetItems ของโครงการที่คุณเป็นเจ้าของเอง (ตามสเปกหัวข้อ 3 และ FS-01b)

ข้อมูลอ้างอิงกลาง (fundSources / ruleVersions / ruleItems / documentTypes / evidenceChains) มีอยู่แล้วใน Firestore จากระบบเดิมซึ่งใช้ฐานข้อมูลเดียวกัน — หน้านี้จึงไม่เขียนทับข้อมูลชุดนั้น เขียนเฉพาะ budgetItems ซึ่งเป็นของใหม่เท่านั้น

หมายเหตุสิทธิ์: budgetItems เขียนได้เฉพาะเจ้าของโครงการ (แม้เป็น admin ก็เขียนของคนอื่นไม่ได้ — ดู firestore.rules) หน้านี้จึงใส่ข้อมูลลง โครงการของบัญชีที่ล็อกอินอยู่ตอนนี้เท่านั้น กดซ้ำได้ ไม่เกิดข้อมูลซ้ำ (ใช้ doc id เดิมทุกครั้ง)
